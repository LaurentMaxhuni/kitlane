# Package metadata attribution

`provider-index.json` contains factual package names, identifiers, homepages and
cross-references from Homebrew Cask and Flathub AppStream. Source URLs, SHA-256
digests and snapshot date are recorded in the index. Descriptions, screenshots,
package scripts and binaries are not redistributed by this index.

- Homebrew Cask: https://github.com/Homebrew/homebrew-cask (BSD-2-Clause).
- Homebrew API: https://formulae.brew.sh/docs/api/.
- Flathub metadata: https://dl.flathub.org/repo/appstream/x86_64/appstream.xml.gz.
  AppStream metadata is supplied by the respective application projects; names
  and trademarks belong to their respective owners. Inclusion does not imply
  publisher endorsement or official maintenance of a package.

WinGet metadata retains its existing `winget-LICENSE.txt` notice.
