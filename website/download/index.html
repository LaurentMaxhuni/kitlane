Before you get started.

A few practical details about the preview.

Which download should I choose?

Choose Windows x64 for a 64-bit Intel or AMD Windows computer. On Mac, check About This Mac: an Apple M-series chip needs Apple Silicon; an Intel processor needs Intel Mac. On Linux, uname -m shows x86_64 for x64 or aarch64 for ARM64.

Will I need Rust or Node.js to run it?

No. Every download contains the native app. Linux also needs the system libraries and credential service listed in its README.

Why might my computer show a security warning?

These early preview downloads have no publisher certificate or Apple notarization. Download only from this site’s GitHub release links, check the published checksums, and follow your device policy. See Apple’s guidance for macOS.

What does uninstalling remove?

The Windows uninstaller removes application files and shortcuts. On macOS, remove Kitlane from Applications; on Linux, remove the extracted folder. Your separately stored local inventory and preferences remain.

Can I try the project from source?

Yes, with the documented Rust toolchain and a configured account service. Follow the app development instructions. Interactive macOS and Linux validation is still pending.
