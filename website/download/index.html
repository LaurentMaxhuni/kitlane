Before you get started.

A few practical details about the preview.

Why isn’t there a download button yet?

The Windows installer is being prepared for public release. Account sign-in and the packaged build need release verification before distribution. Check GitHub releases for published builds.

Will I need Rust or Node.js to run it?

No. Packaged Windows releases contain the native app. Rust and Node.js are development tools, not requirements for running the packaged app.

What does uninstalling remove?

The Windows uninstaller removes application files and shortcuts. It retains your local Kitlane inventory and preferences, so uninstalling doesn’t erase your setup history.

Can I try the project from source?

Yes, with the documented Rust toolchain and a configured account service. Follow the app development instructions. macOS and Linux runtime validation is still pending.
